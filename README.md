# whoami

박유진의 자기소개 페이지. 레트로 게임의 스테이지 셀렉트 화면을 흉내 낸
단일 HTML 파일입니다.

**→ https://use-in.github.io/whoami**

## 구성

- `index.html` — 페이지 전체 (마크업 + CSS 인라인)

글꼴은 두 곳에서 불러옵니다. Google Fonts에서 Press Start 2P(라틴·숫자),
jsDelivr에서 Galmuri11(한글)입니다. 그 외 외부 의존성은 없습니다.

## 로컬에서 보기

`index.html`을 브라우저로 열면 끝입니다. 빌드 과정이 없습니다.

## 수정하기

`index.html` 하나만 고치면 됩니다. `main` 브랜치에 푸시하면
GitHub Pages가 자동으로 다시 배포합니다.

- 색·글꼴은 파일 상단 `:root` 의 CSS 변수에서 한 번에 바꿉니다
  (게임 화면이라 어두운 한 벌만 있습니다)
- 스테이지를 늘리려면 `.stages` 안에 `<article class="stage">` 를 하나 더 넣고
  라벨·번호·제목·부제만 채우면 됩니다. 3열 격자가 알아서 받습니다
- 관심 분야와 연락처는 아직 비워 둔 상태입니다. 부제 자리의 `???` 를
  내용으로 바꾸면 됩니다
- 지금 고른 칸을 옮기려면 빨간 `▶` 커서(`<span class="cur">`)를
  다른 카드의 제목 앞으로 옮깁니다

색을 어디에 쓰는지, 왜 그렇게 나눴는지는 `DESIGN.md` 에 적어 두었습니다.
